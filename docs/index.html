goodLAC user manual

goodLAC is a local-first authority and effect-control boundary for agent systems. An AI model may propose an action; deterministic controller code decides whether the action is authorized and whether the bounded effect may occur.

Central invariant: Model output is never authorization.

What this manual covers

This documentation applies specifically to 1.0.0-rc.12, the first goodLAC release intended for ordinary public use. It covers the qualified Linux reference path, default-governed Pi, project identity, permissions, owner administration, provider and external-consumer boundaries, security architecture, durable effect truth, troubleshooting, rollback, licensing, support, and public project policy.

Qualified reference path

  • Linux reference platform.
  • Pinned Pi 0.85.1 reference harness.
  • Four model-facing consequential tools: lac_fs_read, lac_fs_create, lac_fs_replace, and lac_shell_exec.
  • Controller-owned policy, approvals, identity, leases, receipts, emergency state, and capability registry.
  • Explicit dangerous bypass for owner/debug use; that path is not governed.
