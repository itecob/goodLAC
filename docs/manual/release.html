Release information and known rc.12 limitations

1.0.0-rc.12 is the first goodLAC release intended for ordinary public use.

Release identity

Accepted private rc.12 source candidate: f83fcf57a30b85288796f04161c8e1fc2fc28936.

The public repository preserves a privacy-sanitized historical lineage. Earlier development states are provenance, not recommendations to deploy those states.

Qualified platform

The accepted reference path is Linux. Qualification claims do not automatically extend to unreviewed operating systems, modified builds, alternate harnesses, unrelated runtime combinations, or future dependency revisions.

Known limitations

  • No one-command public bootstrap for the heavyweight managed Pi/FreeToken/model runtime assets.
  • No generic provider/adapter first-connect admission gate in rc.12.
  • The default governed Pi model-facing consequential surface is exactly four LAC tools; generic Gmail/Calendar adapters are separate integration capabilities.
  • The v0.1 owner admin boundary is designed for a single-owner Linux machine and does not claim protection from arbitrary unsandboxed software already running as that same owner UID.
  • No qualified goodLAC verify-install system exists.
  • No general long-term-support, maintenance, response-time, or SLA commitment is published.

Do not infer roadmap features

Future design ideas are not current authority properties. In particular, capability registration plus effect permission is not equivalent to generic provider/adapter admission approval.

This manual documents goodLAC 1.0.0-rc.12. Model output is never authorization.
