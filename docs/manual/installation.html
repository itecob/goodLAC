Installation and prerequisites

rc.12 uses a source-install path and deliberately fails closed rather than silently downloading or substituting qualification-sensitive runtime dependencies.

Supported public baseline

  • Linux
  • Python 3.10+
  • Git
  • Node.js compatible with the pinned Pi requirement (>=22.19.0)
  • Bubblewrap (bwrap)
  • fd
  • rg / ripgrep

The accepted managed local-model path additionally expects the exact qualified Pi and FreeToken checkouts, accepted local model/runtime assets, and the runtime environment used by that path. The accepted FreeToken runtime path was qualified with a CUDA 13 toolkit.

1. Clone goodLAC

git clone https://github.com/itecob/goodLAC.git
cd goodLAC

2. Provision pinned Pi

Expected checkout: ~/.cache/local-agent-controller/phase0/upstream/pi
Pinned commit: da840b6216578c2a571d0374ac6a2091a83f9d91

mkdir -p ~/.cache/local-agent-controller/phase0/upstream
git clone https://github.com/earendil-works/pi.git   ~/.cache/local-agent-controller/phase0/upstream/pi
git -C ~/.cache/local-agent-controller/phase0/upstream/pi   checkout --detach da840b6216578c2a571d0374ac6a2091a83f9d91
python3 scripts/verify_pi_pin.py

Install the pinned checkout's JavaScript dependencies using that checkout's upstream package-manager instructions. Do not substitute a different revision.

3. Provision pinned FreeToken

Expected checkout: ~/.cache/local-agent-controller/phase0/upstream/freetoken
Pinned commit: af71ba43206e124f5ff6419b47ee36c6e9981078

git clone https://github.com/FlashML-org/FreeToken.git   ~/.cache/local-agent-controller/phase0/upstream/freetoken
git -C ~/.cache/local-agent-controller/phase0/upstream/freetoken   checkout --detach af71ba43206e124f5ff6419b47ee36c6e9981078
python3 scripts/verify_freetoken_pin.py
No one-command heavyweight runtime bootstrap exists in rc.12. The managed launcher expects already-provisioned qualified runtime/model assets and does not silently substitute a model, FreeToken revision, CUDA environment, or other qualification-sensitive dependency.

4. Build and install

mkdir -p dist
python3 scripts/lac-v1 build   --output dist/local-agent-controller-1.0.0-rc.12.tar.gz

python3 scripts/lac-v1 install   --archive dist/local-agent-controller-1.0.0-rc.12.tar.gz

The distribution is built from the Git index, not arbitrary unstaged worktree bytes.

5. Verify

~/.local/bin/lac-doctor --static

After Pi, FreeToken, and the local-model runtime assets are provisioned:

~/.local/bin/lac-doctor

A complete managed-runtime installation should report "ok": true.

lac-piCompatibility alias for the governed Pi path.
