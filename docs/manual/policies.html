Licensing, support, community policy, and references

This page points to the controlling public project documents. The linked files, not this summary, contain the complete legal and policy terms.

Licensing

The operative public licence is the goodLAC Community License v1.0. The repository describes free personal, research/educational, and internal organizational use subject to the licence, while Productized Use and Third-Party Operational Use require separate commercial licensing.

Commercial licensing: COMMERCIAL-LICENSING.md · enquiries: support@itecob.com.

Support

The Community License does not include a general support, maintenance, response-time, or service-level commitment. See SUPPORT.md.

Security reporting

Use GitHub Private Vulnerability Reporting. Do not disclose unresolved vulnerabilities publicly. See SECURITY.md.

Contributions and discussion

External code and other copyrightable contributions are currently closed. Bug reports, feature requests, reproducible technical observations, ideas, and technical discussion are welcome. No CLA is active for external contributions. See CONTRIBUTING.md and GitHub Discussions.

Code of Conduct

Community participation is governed by the public Code of Conduct.
