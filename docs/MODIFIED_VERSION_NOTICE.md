# Modified goodLAC Version Notice

The goodLAC Community License requires every Modified Version to carry a clear, prominent modification notice.

The required **substance** is binding. Exact wording is not required.

A maintainer may copy and paste the following notice verbatim:

> **Based on goodLAC by ITECOB Inc.**
>
> This version has been modified from the official goodLAC distribution and is not an official ITECOB Inc. release.
>
> ITECOB Inc. has not reviewed, verified, certified, approved, or endorsed these modifications and makes no representation that this modified version preserves the security, authority, compatibility, or operational properties of the official goodLAC release.
>
> ITECOB Inc. does not provide support for these modifications or for this modified distribution.

A translated or differently worded notice is acceptable if it clearly communicates all required facts.

The notice should live inside the modified repository/package/distribution itself so it remains attached when the modified version is copied or moved. A download page may repeat the notice but should not be the only place it appears.
