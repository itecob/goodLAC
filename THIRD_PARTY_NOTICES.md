# Third-Party Notices

## Phase 0 status

No third-party implementation source is incorporated into the Local Agent Controller product by this bootstrap package.

Phase 0 clones pinned upstream revisions into a local qualification cache for inspection and testing. Those upstream checkouts retain their own license files and are not copied into LAC product source.

If later implementation copies, modifies, vendors, or redistributes upstream code, this file and `UPSTREAM_LOCK.json` must be updated before that code is accepted.

Waggle remains concepts-only unless an authoritative license is resolved at the exact revision intended for reuse.
