# goodLAC Conformance Relationship

goodLAC Conformance is intended to be a **separate repository/project** in the goodLAC and ITECOB Inc. ecosystem.

It is not implemented in this core repository merely because this document describes the relationship.

## Intended purpose

The intended purpose is:

> Assess one exact repository/version against the goodLAC requirements using evidence contained in that repository.

The conformance system is intended to make reproducible integration assessment easier. It is not intended to recommend repositories or substitute for deployment-specific security review.

A conformance assessment does **not**:

- recommend the assessed repository;
- guarantee security;
- guarantee that software is vulnerability-free;
- assess the user's full system or operating environment;
- assess unrelated dependencies merely because they exist elsewhere in a supply chain;
- assess past or future versions not included in the assessment; or
- imply certification, endorsement, verification, partnership, or approval by ITECOB Inc.

The intended outcome language is neutral and factual rather than a recommendation or quality ranking.

## Separate project status

A separate goodLAC Conformance project is being developed to help users evaluate whether external repositories satisfy goodLAC integration requirements.

No repository URL is asserted here until the separate project is actually published.

## Intended licensing split

### Written specification and matrix

The written goodLAC Conformance Specification and assessment matrix are intended to be licensed under:

**CC BY-SA 4.0**

Published derivative specifications are intended to preserve the applicable attribution and ShareAlike obligations.

### Official verifier and evidence tooling

The official verifier, evidence tooling, and automation are intended to use the separate goodLAC source-available/commercial-use model:

- personal/internal use is intended to be free under the activated goodLAC Community License; and
- commercial productization or third-party operational use is intended to require an ITECOB Inc. commercial license.

The CC BY-SA licensing intent for the written specification must not be applied automatically to executable verifier code.

## Conformance versus brand endorsement

A technically reproducible conformance assessment and permission to use official goodLAC endorsement language are separate matters.

A party may accurately describe what a reproducible conformance assessment found without self-awarding claims such as "goodLAC Certified", "goodLAC Verified", "Official goodLAC Partner", or equivalent ITECOB endorsement.
